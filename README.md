My cat is my alarm clock: she goes off at 5 a.m., cannot be snoozed, and bites when I hit her.

One line, 94 characters. Entry for the make.fun competition "The One-Line Cat Joke That Lands" — a single joke about cats, judged pairwise by a stand-up comic brief: setup + turn, laugh out loud on first read, surprise, few words, retellable the same day.

`main.ts` (Node 22, stdlib only) writes the joke to `/output/entry.txt` (or `$ENTRY_OUTPUT`).
